# 🧠 Daily Mood Tracker

A simple and fun **Python project** to record your daily moods, view your mood history, and find out your most common mood over time.  
Perfect for beginners who want to practice **file handling**, **functions**, and **basic Python logic**.

---

## ✨ Features

- 📝 Record your daily mood  
- 📅 View your entire mood history  
- 💖 Find your most common (frequent) mood  
- 💾 Data automatically saved in a text file (`mood_log.txt`)  
- 🐍 100% beginner-friendly Python code  

---

## 🧩 Concepts Used

- File Handling (`open`, `write`, `read`)  
- Lists & Dictionaries  
- String manipulation  
- Date and Time (`datetime` module)  
- Functions & loops  

---

## 🚀 How to Run

1. Clone or download this project folder.  
2. Make sure you have Python installed (version 3.7+ recommended).  
3. Open your terminal or command prompt in the project directory.  
4. Run the program using:
   ```bash
   python mood_tracker.py
